## The format finding (why the death survived every fence fix)

Upload #1 is xenos format 23 = `k_24_8_FLOAT` -> deko 45 = **ZF32_X24S8**, a
DEPTH format. The copy-sync and bisect proofs used RGBA8 and never covered it.
Hypothesis (host-side; the deko3d API does not reject depth formats, it copies
them raw): depth/stencil is not a supported 2D-copy destination on Tegra, so a
buffer->image copy into ZF32_X24S8 is an invalid DMA -> GPU fault -> OS kill
~100 ms after the kick. This run MEASURES it: skip -> survive = confirmed.
Batch: #1 ZF32_X24S8 960x720, #2 RGBA8 480x360 (deko 28), #3/#4 RGB10A2 240x180
(deko 52). Runs 043-048 survived 40+ s because their copies never executed
(unfetched); every run whose copies execute dies right after this batch.

Note on the staging hypothesis: in run 069 no retirement ran between upload #4
and death (retirement only runs on later uploads; there were none), so the
age-free mechanism did not fire this run. It IS a latent bug (the old
present-epoch+2 rule could free a block before its long frame was submitted),
and it is fixed here as ordered - but the depth copy is the stronger suspect,
so this run measures both.

## What this build changes

1. **Staging lifetime pinned to frame cohorts (never age).** A block recorded
   into the frame list is pinned to cohort = FrameSubmitEpoch()+1 (the frame it
   rides) and released only when PresentEpoch() >= cohort+1 - a LATER frame's
   present fence has signalled, which on the in-order queue proves the cohort's
   copies completed. Same rule for the standalone fallback (own fence primary,
   cohort witness secondary). `[staging] released N block(s) on the
   present-fence witness` logs the releases; `[frame] submit #N carried U
   upload copy/copies` names what rode each frame.
2. **Depth/stencil uploads skipped** (`deko3d_upload_skip_depth = true`,
   opt-out): S8/Z16/Z24X8/ZF32/Z24S8/ZF32_X24S8 sample the placeholder (the
   pre-run-043 behaviour that survived 40+ s) until a DKSH resolve exists.
   `[upload] SKIPPED depth/stencil format (xenos 23 -> deko 45) ...` names every
   skip. The probe now arms on the first NON-depth upload (RGBA8 480x360).
3. **Probe prints a 4x4 pixel grid** alongside the changed-byte count; still
   presenter-polled every present, CpuUncached block.
4. Guest-output readback (#30/#150), per-frame drew/skipped census,
   skip-census and death-watch: unchanged, kept.
